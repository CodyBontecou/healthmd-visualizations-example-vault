# Health.md Visualizations Example Vault

This is an example Obsidian vault designed to work alongside the [Health.md Visualizations community plugin](https://community.obsidian.md/plugins/health-md).

It includes sample Apple Health-style JSON data and dashboard notes that demonstrate the plugin's `health-viz` code blocks.

## What's included

- `Health/` — mock health data files for charting and dashboard examples.
- `apple-dashboard.md` — Apple Health-inspired overview dashboard.
- `daily-dashboard.md` — single-day health dashboard.
- `weekly-overview.md` — rolling weekly overview.
- `sleep-analysis.md` — sleep-focused dashboard.
- `visualization-reference.md` — reference examples for supported visualization types and arguments.

## Usage

1. Install Obsidian.
2. Install the [Health.md Visualizations plugin](https://community.obsidian.md/plugins/health-md) from the Obsidian community plugin browser.
3. Clone or download this repository.
4. Open this folder as an Obsidian vault.
5. Open one of the dashboard notes to see the example visualizations.

The bundled data is intended as an example dataset so the dashboards render consistently in a fresh vault.
